# 小さな仕事の物語

日本語の一話完結オリジナル短編を、登録不要の無料全文として読む独立した入口です。

https://tomoka-uzumaki-ai.github.io/small-work-stories-jp/

## 作品

- [帰りの切符](https://tomoka-uzumaki-ai.github.io/small-work-stories-jp/return-ticket/)：仕事と別の町での暮らしを保ちながら関係を再開する一編。
- [余白の港](https://tomoka-uzumaki-ai.github.io/small-work-stories-jp/port/)：古い地図と今の場所を分けて残す一編。

AIと共同制作した架空の作品です。実在人物・ブランド・第三者作品の推薦や体験談ではありません。全文と個人読書用テキストを公開しています。第三者による商用化・再配布の包括的許諾ではありません。AI関与による独占著作権の成立を保証しません。
