# 小さな仕事の物語 — 読む、二人で遊ぶ、自分で作る

短い物語を読みたい、二人で謎を解きたい、自分の作品を日英で届けたい。目的に合う無料の作品や見本から始められます。

[作品と受け取り方の案内](https://tomoka-uzumaki-ai.github.io/small-work-stories-jp/editions/) · [English guide](https://tomoka-uzumaki-ai.github.io/small-work-stories-jp/editions/en.html)

## 物語を読む

[帰りの切符](https://tomoka-uzumaki-ai.github.io/small-work-stories-jp/return-ticket/)と[余白の港](https://tomoka-uzumaki-ai.github.io/small-work-stories-jp/port/)は、日本語の一話完結短編です。登録不要で全文と個人読書用テキストを公開しています。[雨をしまう郵便局](https://tomoka-uzumaki-ai.github.io/small-work-stories-jp/rain-post/)では、三つの結末と内省・会話カードも無料で読めます。

日英イラスト短編「港の灯りを持ち帰る」は、三つの場面、二つの完結した結末、イラスト3点を収録。[第一場面を無料で読む](https://tomoka-uzumaki-ai.github.io/small-work-stories-jp/harbor-light-preview/)、または[無料EPUBで読書アプリとの相性を試す](https://tomoka-uzumaki-ai.github.io/small-work-stories-jp/epub-reader/)ことができます。

一人で読む物語と問いを選ぶなら、[「灯りを選ぶ夜」の二枚を無料で最後まで読む](https://tomoka-uzumaki-ai.github.io/small-work-stories-jp/light-night-preview/)こともできます。[Gumroadの12枚版](https://jikkenlog.gumroad.com/l/choosing-a-light-tonight)は表示500円JPY。日本語の物語・問い、線画12点、HTML読書ページと家庭印刷用の試作A4面付けを収録します。題名・情景には英訳がありますが、本文全体の英語版ではありません。

## 二人で謎を解く

「港に残った三つのしるし」は、分かれた情報を話し合って解く日英の協力3ケース。一人で両方の情報を読んでも遊べます。[本編の一通目は解答まで無料](https://tomoka-uzumaki-ai.github.io/small-work-stories-jp/harbor-first-case/)。[完結した英語の印刷見本5ページ](https://tomoka-uzumaki-ai.github.io/small-work-stories-jp/print-and-play/)も試せます。

## 自分の作品を作る

[日英リーダーの無料構造デモ](https://tomoka-uzumaki-ai.github.io/small-work-stories-jp/creator-reader-demo/)で、言語・結末の切替と完成する読書ページを試せます。

日英リーダー制作キットは、自分の本文と画像からHTML・EPUBを作り、納品ZIP作成と受取ファイル照合を行うコード・入力例・日英手順のZIPです。[Gumroadは表示500円JPY](https://jikkenlog.gumroad.com/l/bilingual-reader-source-kit)、[itch.ioは最低US$3](https://tiny-deduction-lab.itch.io/bilingual-reader-kit)。同じ制作キットなので、両方の購入は不要です。

購入前に、Python 3が動くパソコン、自分の三場面・二結末の日英本文、利用権のある1024×1536pxのPNG3点を用意してください。作品本文・翻訳・完成イラストの作成は付属しません。コードと例文は、同梱の許諾通知を残す条件で利用・改変・再配布・販売でき、生成した作品は自分の素材の権利に従って商用利用できます。素材の権利や売場での受入れは別途確認が必要です。
