Who this kit is for

Authors combining a three-scene, two-ending Japanese/English story with three portrait illustrations. You need a computer with Python 3.10, your own translations and authorized images. It is not for arbitrary scene counts or phone-only production.

Your own usage terms

Supply your own text for the story, translations and artwork. The tool saves it as UTF-8 without writing a license or judging your rights. HTML input preparation works without this text; EPUB and delivery need a nonempty rights.txt.

Try your Python environment before authoring

Extract the ZIP in your purchased kit folder to get content.json and the three PNGs in art. Generator code is not included.
Build into a new output folder: python3 -X utf8 build_reader.py --content content.json --art art --out reader-new. Then open reader-new/index.html and check both languages, both endings and all images. Existing output files can be overwritten, so use a new folder name.
With rights.txt included: python3 -X utf8 build_epub.py --content content.json --art art --rights rights.txt --out own-story-new.epub. The generator comes with the purchased kit. Use a new output file.
