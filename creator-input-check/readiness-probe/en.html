Try Python before creating your story

probe.py — save the free check

Before buying an authoring kit, try the current Python interpreter and a small local file/ZIP operation. This free check does not use your story or artwork and makes no network requests.

Run on your own computer

  1. Save probe.py below into a new folder where you can write.
  2. Open a terminal in that folder. On macOS or Linux, run python3 probe.py. On Windows, run python probe.py. If that launcher is unavailable, your Python setup needs attention; this page does not install it.
  3. Read the saved creator-environment-result-*.json. It lists the running Python version, standard-module imports, UTF-8 file and Unicode ZIP readback. A fresh temporary folder is removed after the check. Each report gets a new name.

The received kit documents Python 3.10 or later. The check compares against that supported baseline.

To use another writable folder: python3 probe.py --directory . (replace python3 with python on Windows). No administrator permission or package installation is required by this probe.

Continue with your own work

A successful result applies only to this interpreter and the listed operations. It does not run the purchased generator or guarantee your inputs, browser, EPUB app, printer or rights. Windows behavior has not been tested on an actual Windows machine.
