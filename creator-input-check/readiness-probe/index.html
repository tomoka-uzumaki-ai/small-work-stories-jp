作品を作る前に、Pythonで小さく試す

probe.py を保存する

作者キットの購入前に、今のPythonと小さなファイル・ZIP操作を自分のパソコンで試せます。無料です。物語や画像を入力せず、通信もしません。

自分のパソコンで実行する

  1. 下のprobe.pyを、書き込める新しいフォルダに保存します。
  2. そのフォルダでターミナルを開きます。macOS/Linuxでは python3 probe.py、Windowsでは python probe.py を実行します。コマンドが見つからない場合はPythonの設定を確認してください。このページからインストールは行いません。
  3. 保存されたcreator-environment-result-*.jsonを読みます。実行中のPython版、標準モジュールの読込、UTF-8ファイルと日本語名ZIPの書込・読戻しが記録されます。確認用に新しく作った一時フォルダは終了時に削除し、結果は毎回新しい名前で残します。

受取キットの手順書はPython 3.10以降を対応前提としています。その前提と今の実行環境を比べます。

保存場所を指定する例：python3 probe.py --directory .（Windowsではpython3をpythonへ）。この確認スクリプトに管理者権限や追加パッケージのインストールは不要です。
